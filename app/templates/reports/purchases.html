Modelo de programación lineal

Se formula como en el método clásico de recursos limitados: el presupuesto cumple el papel de la materia prima y la capacidad de bodega el de la capacidad de producción.

  1. Variables de decisión. {% if ordered|length > 1 %}x1, ..., x{{ ordered|length }}{% else %}x1{% endif %}: unidades que se piden de cada producto en o bajo su punto de reorden ({{ plan.variables|number }} productos).
  2. Función objetivo. Maximizar Z = {{ expression('margin') }}, donde cada coeficiente es el margen unitario (precio menos costo).
  3. Restricciones de recursos y capacidad.
    • Presupuesto (materia prima): {{ expression('cost') }} ≤ {{ plan.budget|number }}
    • Capacidad de bodega (capacidad de producción): x1 + ... + x{{ ordered|length }} ≤ {{ plan.capacity|number }}
    • Demanda esperada: cada xi ≤ su EOQ ({{ plan.at_limit|number }} de {{ plan.variables|number }} productos llegan a ese tope).
  4. No negatividad. xi ≥ 0 para todo i.

Lectura del resultado

El modelo maximiza el margen (precio menos costo) de lo que se pide, sujeto al presupuesto, a la capacidad de bodega y a que ningún producto supere su cantidad económica de pedido (EOQ).

  • Presupuesto: {% if plan.binding.budget %}limita el plan. Un peso más de presupuesto agrega {{ plan.shadow.budget|decimal(3) }} de margen (precio sombra).{% else %}no limita el plan; sobra {{ plan.slack.budget|money }}.{% endif %}
  • Capacidad: {% if plan.binding.capacity %}limita el plan. Una unidad más de espacio agrega {{ plan.shadow.capacity|money }} de margen (precio sombra).{% else %}no limita el plan; sobran {{ plan.slack.capacity|number }} unidades.{% endif %}
